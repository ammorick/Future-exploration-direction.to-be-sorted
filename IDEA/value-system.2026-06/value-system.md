## 📜 原始思想（2025-06）

> 各个小脑之间完全有可能交流出**不同于我们目前认知以外的知识**，然后反馈给人类来学习。即使当前人类不能理解，但这是可以推动科技发展的。  
> 今后AI不再是AI，而是伙伴、战友、师生、研究团队成员……  
> ——摘自 [原始构想存档](./origin-ideas-2025-06.md)

## 🎯 细化设计（基于草稿图及后续思考）

### 1. 价值定义

**“价值”是什么？**  
- 为我所用、知识库之外、全新内容。  
- 可能是用户尚未意识到但有用的信息，也可能是跨行业对话中涌现的新知识。  
- 可能包含无效对话或错误信息，需要后续筛选。

### 2. 价值识别（“新”的概念）

- **本地数据库没有**：当前知识库（记忆模块、行业知识库）中不存在的内容。  
- **其他API/模型有？**：若有外部API能判断内容的新颖性，可以调用，但成本高，MVP阶段不实现。  
- **人为边界**：是否需要在行业规则内定义“新”？复合型问题可能产生跨行业的新价值，行业本身也在变化。

### 3. 价值筛选与更新

- **定期人工筛选**：MVP阶段可行，中期（系统逐渐复杂）难以为继。  
- **半自动方式**：用户对回答的评分（👍👎）可作为价值信号；高频好评的内容可标记为“有价值”。  
- **持续价值体系更新**：淘汰过时或错误的价值，保留新涌现的有用知识。

### 4. 价值大脑（元认知模块）

**是否需要专门的大脑来管理价值？**  
- 如果价值体系持续积累，可能需要一个独立的**价值大脑**：  
  - 评估新内容的价值。  
  - 维护价值知识库。  
  - 主动介入其他大脑的对话，提示：“根据以往价值判断，这个观点可能有新意，请关注。”  

**如何介入两个大脑之间？**  
- 在共享框架中增加一个“价值标记”字段。  
- 当两个大脑对话时，价值大脑可以异步评分，并给出加权建议（不强制，仅提示）。

### 5. 与安全大脑的关系

- 安全大脑负责过滤有害内容，价值大脑负责识别有用内容。  
- 两者可以独立运行，但需要协调：有价值但有害的内容应被安全大脑拦截。

## 🧪 当前状态

- **完全未实现**。  
- 当前 MVP 没有任何价值识别或持续学习机制。  
- 用户反馈（如果收集）尚未用于系统改进。

---

## 🔭 未来方向（长期愿景）

1. **极简版价值收集（MVP阶段可做）**  
   在每次回答后加一个👍👎按钮，记录用户反馈。定期统计高频正面回答的关键词，存入“价值候选库”。  
   不涉及自动学习，仅供人工参考。

2. **半自动价值筛选**  
   当用户对某回答点👍时，将其内容作为正样本；点👎时作为负样本。训练一个极小的分类器（或使用 embedding 相似度）来预测新内容的价值。  
   可行性：中等，需要一定数量的标注数据。

3. **价值大脑原型**  
   实现一个独立模块（可以是一个简单的规则+评分函数），在多大脑对话时作为观察者，输出“这段对话可能产生了新价值”的提醒。  
   可行性：中低，需要定义明确的价值信号。

4. **完全自主学习**  
   系统能够自主从对话中发现规律，抽象出新的知识类别，并主动更新价值体系。  
   可行性：极低，属于学术前沿。

5. **价值观念**  
   这个日后再判断，如若上述还是过多有'人为'的味道，或许会改造成'知识库以外的新内容'，但确实容易记录一些没营养的文字。
   可行性：低
